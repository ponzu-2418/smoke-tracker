# smoke-tracker（禁煙サポートアプリ）
毎日のたばこの本数を減らしたい人のための記録アプリ
対比、金額、推移を一目で確認できる

## 開発のきっかけ
身近な喫煙者から「たばこの本数を減らしたいが１日に何本吸っているのか把握できていない」という話を聞いたことがきっかけです。
実際にヒアリングを行い、希望された機能のうち「記録」「目標との対比」「推移の可視化」に絞って開発した。

## 主な機能
・ボタン一つで喫煙本数を記録
・今日の本数と目標本数の対比
・本数に応じてアイコン変化
・今日の金額と累計金額の計算
・直近７日間の推移グラフ
・機能の比較と目標達成日数のコメント表示
